# One Line to Your Younger Self

A single line addressed to the author's younger self — the unmailed letter to Dad, and the door that may not have anyone left to open it. The program writes that one line to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (one line, 119 characters, no trailing newline). Deterministic, Node stdlib only, no network.
